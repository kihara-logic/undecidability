タイルの庭

ワンのタイルで庭を埋める．小さな額縁の庭から始めて，やがて果てのない平面へ．

試作版 v1.7（第 1〜9 層）．進み具合はこのブラウザにだけ保存されます．

    手引き

      盤の操作
      行 　列

      手持ちのタイル

      何度でも使える．マスへドラッグ（タップで選んでからマスをタップしてもよい）

      書換えの記録（新しいものが上）

      このタイルの組で，平面を埋められるか判定したい．手がかりは，これまでに集めた二種類の証拠．

      行き止まりの証拠（第 3 層）n×n の庭が埋まらない → 平面は埋められない
      周期の証拠（第 4 層）トーラスが埋まる → 平面を周期的に埋められる
      nn×n の庭は埋まる？縦横 n 以下のトーラスの盤を埋められる？

      この書換えは，永遠に続けられるか．手がかりは，二種類の証拠．

      ✕ 行き止まりの証拠深さ n までに，すべての道が行き止まる → 永遠には続かない
      ↻ 再来の証拠同じ語が再び現れる道がある → 永遠に続く
      n深さ n までに，すべての道が行き止まる？深さ n までに，同じ語が再び現れる？

      ここに，調べた結果や周期の展開が表示される．
